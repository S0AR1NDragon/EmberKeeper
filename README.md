# EmberKeeper — рабочий стол мастера D&D

Нативное приложение для мастера Dungeons & Dragons: карта с токенами, инициатива, слайды,
листы героев и НПС, библиотека dnd.su (2014 и 2024 отдельно), генераторы и связи.

## Возможности

- **Карта**: несколько локаций, фон, сетка (квадрат/гекс), привязка к клеткам, туман войны,
  стены, шаблоны, пропсы, линейка, аура и свет токенов, скрытые от игроков токены.
- **Экран игроков** (второй монитор): карта с инициативой, сцены, пустой экран — переключается мгновенно.
- **Инициатива**: бойцы, броски, раунды, подсветка активного токена, обмен ХП с картой.
- **Слайды**: сцены с фоном, текстом и перетаскиваемыми элементами (картинки, поворот, прозрачность).
- **Герои**: лист персонажа с характеристиками, спасбросками, навыками, заклинаниями;
  импорт JSON и Long Story Short; выгрузка на карту.
- **НПС**: карточки, теги, фильтры, музыка внутри приложения.
- **Библиотека**: заклинания, предметы, черты, классы, виды, бестиарий, предыстории — 2014 и 2024.
- **Связи**: граф отношений персонажей, фракций и мест.
- **Генераторы (15 наборов)**: связи между персонажами, характер НПС, случайные стычки
  (сразу на карту), колода вещей, колода судьбы, таверны, слухи, зацепки, имена,
  поселения, тайны, проклятия, погода, сундуки, «что за неделю».
- **Кости**: d2–d100, количество, преимущество/помеха, своя формула, история бросков.
- **Экспорт/импорт кампании** в один JSON, темы (тёмная/светлая), горячие клавиши.

## Установка

Скачайте установщик из [Releases](../../releases) и запустите.
Ставится для текущего пользователя, права администратора не нужны.

Либо портативная версия: распаковать архив и запустить `EmberKeeper.exe`.
Данные кампании лежат в папке `campaign` рядом с программой.

## Лицензия

Программа требует лицензионный ключ (офлайн-проверка подписи, привязка к компьютеру).
Без действующего ключа работа невозможна.

## Сборка из исходников

Нужен .NET SDK 8.

```powershell
# обычная сборка
dotnet build EmberKeeper/EmberKeeper.csproj -c Release

# установщик + портативный архив в папку dist
powershell -ExecutionPolicy Bypass -File build-installer.ps1
```

### Структура

| папка | что внутри |
|---|---|
| `EmberKeeper/` | само приложение |
| `installer/` | установщик (EmberKeeperSetup) |
| `licensegen/` | инструмент выпуска лицензий (нужен приватный ключ) |
| `keys/` | только публичный ключ лицензий |
| `data/` | библиотека dnd.su (JSON) |

## Обновления

В приложении: **Главная → ⟳ Обновления**. Проверяются релизы этого репозитория;
новый установщик скачивается и запускается автоматически.

Для выпуска обновления: собрать установщик, создать Release с тегом `vX.Y.Z`
и прикрепить `EmberKeeperSetup-X.Y.Z.exe`.
