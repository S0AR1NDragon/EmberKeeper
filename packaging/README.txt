 EMBERKEEPER 1.0 — памятка
 =========================

 УСТАНОВКА
   EmberKeeperSetup-1.0.0.exe — запустить и подтвердить.
   Права администратора не нужны, ставится для текущего пользователя.
   Ярлыки появятся в меню «Пуск» и на рабочем столе.
   Данные кампании: папка campaign рядом с программой.

   Если рядом с установщиком лежит license.key — он установится автоматически.

 БЕЗ ЛИЦЕНЗИИ
   При первом запуске программа показывает окно активации с «кодом компьютера».
   Без действующего ключа главное окно не открывается.

 ВЫПУСК КЛЮЧА (владельцу программы)
   1. Запустите make-license.cmd (двойным щелчком) — он спросит имя,
      код компьютера клиента и срок. Готовый ключ скопируется в буфер обмена
      и сохранится в папку licenses.
   2. Либо вручную:
        tools\license-tool\EmberKeeperLicenseGen.exe --issue --name "Иван" ^
            --machine КОД --days 365 --keys keys --out ivan.key

      --machine *   — без привязки к компьютеру
      --days 0      — бессрочно
      --verify файл — проверить ключ

   ВАЖНО: файл keys\private.pem — ваш секретный ключ. Храните его отдельно,
   сделайте резервную копию, никому не передавайте. В репозиторий он не входит
   и в поставку не включается.

 ОБНОВЛЕНИЯ
   В программе: «Главная» → «⟳ Обновления» → «Проверить обновления».
   Проверяются релизы репозитория github.com/S0AR1NDragon/EmberKeeper.

   Выпуск обновления:
     1. Собрать установщик:  build-installer.ps1 -Version 1.1.0
     2. Запушить исходники.
     3. GitHub → Releases → Draft a new release, тег v1.1.0,
        прикрепить EmberKeeperSetup-1.1.0.exe.
   Пользователи получат обновление по кнопке.

 ПЕРЕСБОРКА
   powershell -ExecutionPolicy Bypass -File build-installer.ps1
   Результат — в папке dist.
